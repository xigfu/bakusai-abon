# 爆サイの荒らしレスをあぼーん

爆サイの指定したスレッドで、絵文字や登録した言葉・顔文字・記号を含むレス本文を「あぼーん」または空白で非表示にするユーザースクリプトです。

## 初めて使う方へ

**[導入手順と設定方法の案内ページを開く](https://xigfu.github.io/bakusai-abon/)**

まずは上の案内ページを開き、使うブラウザを選んで、順番に進めてください。コードをコピーしたり、プログラムを書いたりする必要はありません。禁止ワード・顔文字・記号のサンプルも掲載しています。

Androidスマホでは **Firefox**、iPhoneでは **Safari** で案内ページを開いてください。

## 動作確認した環境

- Windows版 Google Chrome ＋ Tampermonkey
- Windows版 Firefox ＋ Tampermonkey
- Android版 Firefox ＋ Tampermonkey

- iPhone SE（第3世代）の Safari ＋ Userscripts

macOSでは動作未確認です。

## できること

- 対象のスレッドタイトルを指定し、スレッドごとにルールを設定できます。
- 絵文字の自動判定、禁止ワード、顔文字、記号の判定をそれぞれON／OFFにできます。
- 禁止ワード・顔文字・記号を、設定画面で追加・削除できます。
- 禁止ワードは、カタカナの全角・半角と英字の大文字・小文字を区別せずに判定します。ひらがなとカタカナ、伏せ字は区別します。顔文字・記号は変換せずに判定します。
- 複数のスレッド設定に一致した場合は、それぞれのルールを合わせて適用します。それぞれの設定でONにした分類が判定に使われます。
- 非表示にした本文は「あぼーん」または空白で表示できます。「あぼーん」を押すと本文を一時表示でき、「本文を隠す」で再び隠せます。

導入後は、スレッド画面の右上にある「あぼーん設定」ボタンから設定できます。

## 利用前に知っておいてほしいこと

このスクリプトは、荒らしかどうかを判断するものではありません。登録した文字などに一致すれば、普通の投稿も非表示になります。例えば「枕」を登録すると、設備案内に「枕」が含まれている場合も、そのレス本文が「あぼーん」になります。

変わるのは、自分のブラウザ上の表示だけです。掲示板の投稿自体を削除・変更するものではありません。元の表示に戻す場合は、TampermonkeyまたはUserscriptsでこのスクリプトを無効にして、ページを再読み込みしてください。

設定はブラウザ内に保存され、ほかの端末や利用者には自動で反映されません。このスクリプトには、登録設定や投稿内容を外部へ送信する処理はありません。

## 更新について

- **PC・Android（Tampermonkey）**：GitHub Pagesを更新先に使います。更新設定やアクセス権限によって自動更新できない場合は、案内ページから最新版を開いて上書きしてください。
- **iPhone（Userscripts）**：Safariで案内ページの「iPhone版を開く」を押し、開いたタブのページメニューから「Userscripts」を開きます。緑色の「Tap to re-install」→「Install」の順に押し、爆サイのスレッドを再読み込みしてください。同じファイル名のまま上書きします。

保存済み設定を引き継ぐには、既存のスクリプトを残したまま上書きしてください。

## ファイル

- `index.html`：導入手順、設定方法、登録サンプルの案内ページ
- `emoji-abon.user.js`：PC・Android向けのTampermonkey版 v1.34
- `emoji-abon-ios.user.js`：iPhone向けのSafari・Userscripts版 v1.34.2

爆サイ、Tampermonkey、Userscriptsの公式配布物ではありません。掲示板やブラウザの仕様変更により、動作しなくなる場合があります。
